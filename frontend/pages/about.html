About Ashley

Ashley is a character-chat app for children and teenagers that runs on your own hardware. A child writes the characters and does the talking; a parent sets the safety layer, one child at a time. It talks to a language model on your own network, and every conversation stays on the machine Ashley runs on.

Why the source link is here

The AGPL is a network licence. Anyone who uses this software over a network — including anyone in your household using it right now — is entitled to the source it is running. The link above is how Ashley meets that, so it belongs on a page anybody can reach rather than in a file only the person who installed it will ever open.

You are free to run it, read it, change it and pass it on. If you publish a modified version and let other people use it over a network, the same licence asks you to make your changes available in turn.

The safety model, briefly

Three things wrap every message: the rules chosen for that person, the character the child wrote, and a short set of rules that apply to everybody and cannot be edited from the app. They are sent in that order, with the fixed rules last, because what comes last carries the most weight.

Be clear about what that is. It is prompt-level safety layered over a language model. It reduces risk; it does not eliminate it, and somebody determined enough can talk any model past instructions like these. Conversations are stored unencrypted on this machine, which means a parent can read them. None of it substitutes for knowing roughly what your child is doing.
